# Master Profile: Template

This is your **single source of truth**: a complete, honest record of your career
that the skill draws on to build each tailored CV. It is *not* itself a CV, keep
it long and comprehensive. The more real detail (especially **numbers**) you
capture here, the sharper every tailored CV will be, because the skill can
*select* the most relevant, quantified evidence for each job rather than ask you
for it each time.

Fill in everything you can. Capture **more bullets per role than any single CV
would use**, tailoring picks the best ones for each application. Record real
metrics wherever they exist; the skill will never invent a number, so anything
missing here is a number it will have to ask you for or leave out.

Keep this file updated as your career progresses. Any format is fine (this
markdown, a Word doc, or plain text), the skill reads whatever structure it finds.

---

## 0. CV output rules
Your standing instructions for how your career is presented; the pipeline and the checks
follow them.
- Standard title for each role, and any alternative title allowed for a given kind of posting.
- Roles that may be left out, and how any gap should be framed.
- Names that never appear (for example a confidential client or a current employer).
- An honest description of the kind of practitioner you are, so nothing overclaims.
- The voice for cover letters.
